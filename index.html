Classroom-ready in three steps

Simple enough for a busy school day.

Run a quiz battle using the devices you already have. No programming, hosting account, or separate student app required.

01

Connect locally

Connect the teacher laptop and two phones to the same hotspot or Wi-Fi router. The network doesn't need internet access.

02

Prepare your quiz

Choose a learning area, add or edit multiple-choice questions, and set the points needed to win.

03

Let teams compete

Learners join by QR code or local link. Correct answers earn one point, and the game keeps score automatically.

Built for teachers

Spend less time setting up. More time teaching.

Classroom Quest is designed for teachers who want to integrate technology but don't want to manage web servers and technical packages.

  • Normal Windows installer — no Node.js setup for teachers
  • Separate pages for instructions, dashboard, and question bank
  • Hotspot and QR-code guidance built into the app
  • Works with a phone hotspot on compatible devices
